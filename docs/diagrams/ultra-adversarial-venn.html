What the adjudicator keeps

Every lane in the ultra loop is reviewed twice by opposed reviewers who never see each other's work, then reconciled by a third. This is why the loop logs three numbers per lane rather than one — the interesting findings are the ones only half the pair found, and the centre region is the only place a finding arrives already corroborated.

Structure, not counts. The circles are drawn at equal radius because the three quantities are per-run, not fixed: the ultra loops log raised_p, raised_d and kept per lane precisely so the real proportions can be read afterwards. Reviewers run blind to each other; only the adjudicator sees both files plus the diff, and its output is the lane's single authoritative finding set.
