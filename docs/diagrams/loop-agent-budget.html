Where a full run's agents go

Thirty-five agent invocations at the ceiling of one full loop. Review is thirty of them, and of the thirteen that reach Opus, twelve are review lanes. The loop does not spend its money writing code — it spends it reading code.

One full dev-loop run at its ceiling — three rounds, every lane applicable. Build = implement + tests, two sidekick handoffs. Review & fix = 9 lanes × 3 rounds, plus one fix sidekick per round. Ship = reviewer-verify, the walkthrough author and the walkthrough reviewer. Reviewer tiers are 4 Opus and 5 Sonnet lanes; sidekicks and the walkthrough pair run at the default Sonnet tier. Every column sums to 35. A real run is smaller: rounds 2 and 3 rerun only the lanes that owned accepted findings.
